# Getting Started

This guide walks you through making your first requests to the <AppName /> API.

## Making Your First Request

The simplest way to use the API is to fetch random images. No authentication is required for basic usage.

### Fetch a Random Image

export const FetchRandomExample = () => {
  const baseUrl = useApiBaseUrl();
  return <CodeBlock language="bash">{`curl ${baseUrl}/images`}</CodeBlock>;
};

### Filter by Tags

Include images matching specific tags using `IncludedTags` (AND logic -- all tags must match):

export const FilterByTagExample = () => {
  const baseUrl = useApiBaseUrl();
  return <CodeBlock language="bash">{`curl "${baseUrl}/images?IncludedTags=waifu"`}</CodeBlock>;
};

<FilterByTagExample />

Exclude images with certain tags using `ExcludedTags` (OR logic -- any match is excluded):

export const ExcludeTagExample = () => {
  const baseUrl = useApiBaseUrl();
  return <CodeBlock language="bash">{`curl "${baseUrl}/images?ExcludedTags=maid"`}</CodeBlock>;
};

<ExcludeTagExample />

### Pagination

Control pagination with `Page` and `PageSize`:

export const PaginationExample = () => {
  const baseUrl = useApiBaseUrl();
  return <CodeBlock language="bash">{`curl "${baseUrl}/images?PageSize=10&Page=1"`}</CodeBlock>;
};

<PaginationExample />

### NSFW Content

By default, only SFW images are returned (`IsNsfw=False`). The parameter accepts three values: `False`, `True`, and `All`.

export const NsfwExample = () => {
  const baseUrl = useApiBaseUrl();
  return <CodeBlock language="bash">{`# NSFW images only
curl "${baseUrl}/images?IsNsfw=True"

# Both SFW and NSFW images
curl "${baseUrl}/images?IsNsfw=All"`}</CodeBlock>;
};

<NsfwExample />

See the [Tags](./tags.mdx) page for more details on how tags and NSFW filtering interact.

### Filter by Artist

You can filter images by artist ID using `IncludedArtists`:

export const FilterByArtistExample = () => {
  const baseUrl = useApiBaseUrl();
  return <CodeBlock language="bash">{`curl "${baseUrl}/images?IncludedArtists=1"`}</CodeBlock>;
};

<FilterByArtistExample />

Consult the [API Reference](/docs/category/api) for the full list of available filters (orientation, resolution, file size, animation, and more).

## The `me` and `favorites` Aliases

When authenticated, you can use `me` as a user ID alias to refer to yourself, and `favorites` as an album ID alias to refer to your default favorites album. These aliases simplify common operations:

export const AliasesExample = () => {
  const baseUrl = useApiBaseUrl();
  return <CodeBlock language="bash">{`# Get your own profile
curl -H "X-Api-Key: YOUR_API_KEY" ${baseUrl}/users/me

# List your favorites
curl -H "X-Api-Key: YOUR_API_KEY" ${baseUrl}/users/me/albums/favorites

# Add an image to your favorites
curl -X POST -H "X-Api-Key: YOUR_API_KEY" \\
  "${baseUrl}/users/me/albums/favorites?ImageId=8008"`}</CodeBlock>;
};

<AliasesExample />

## Code Examples

export const CurlExample = () => {
  const baseUrl = useApiBaseUrl();
  return <CodeBlock language="bash">{`curl "${baseUrl}/images?IncludedTags=waifu"`}</CodeBlock>;
};

export const JsExample = () => {
  const baseUrl = useApiBaseUrl();
  return <CodeBlock language="javascript">{`const response = await fetch("${baseUrl}/images?IncludedTags=waifu");
const data = await response.json();
console.log(data.items[0].url);`}</CodeBlock>;
};

export const PythonExample = () => {
  const baseUrl = useApiBaseUrl();
  return <CodeBlock language="python">{`import requests

response = requests.get(
    "${baseUrl}/images",
    params={"IncludedTags": "waifu"}
)
data = response.json()
print(data["items"][0]["url"])`}</CodeBlock>;
};

export const CsharpExample = () => {
  const baseUrl = useApiBaseUrl();
  return <CodeBlock language="csharp">{`using var client = new HttpClient();
var response = await client.GetAsync("${baseUrl}/images?IncludedTags=waifu");
var json = await response.Content.ReadAsStringAsync();
Console.WriteLine(json);`}</CodeBlock>;
};
