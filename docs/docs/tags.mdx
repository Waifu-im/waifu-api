# Tags

Tags are used to categorize images in the <AppName /> archive. Each image can have one or more tags describing its content.

## How Tags Work

A tag is simply a label attached to images. Every tag works the same way, but some tags may only have NSFW images associated with them. If you search for such a tag without adjusting the `IsNsfw` parameter, you will get no results because `IsNsfw` defaults to `False` (SFW only).

### Example

If the tag `hentai` only has NSFW images:

export const HentaiExample = () => {
  const baseUrl = useApiBaseUrl();
  return <CodeBlock language="bash">{`# Returns no results because IsNsfw defaults to False
curl "${baseUrl}/images?IncludedTags=hentai"

# Returns results
curl "${baseUrl}/images?IncludedTags=hentai&IsNsfw=True"`}</CodeBlock>;
};

<HentaiExample />

Tags like `waifu` have both SFW and NSFW images. Using `IsNsfw=All` lets you get both at once:

export const WaifuExample = () => {
  const baseUrl = useApiBaseUrl();
  return <CodeBlock language="bash">{`# Returns SFW waifu images only (default)
curl "${baseUrl}/images?IncludedTags=waifu"

# Returns NSFW waifu images only
curl "${baseUrl}/images?IncludedTags=waifu&IsNsfw=True"

# Returns both SFW and NSFW waifu images
curl "${baseUrl}/images?IncludedTags=waifu&IsNsfw=All"`}</CodeBlock>;
};

<WaifuExample />

## The `IsNsfw` Parameter

| Value   | Behavior                       |
| ------- | ------------------------------ |
| `False` | SFW images only **(default)**  |
| `True`  | NSFW images only               |
| `All`   | Both SFW and NSFW images       |

## Listing Available Tags

Fetch all available tags from the API:

export const ListTagsExample = () => {
  const baseUrl = useApiBaseUrl();
  return <CodeBlock language="bash">{`curl ${baseUrl}/tags`}</CodeBlock>;
};

## Filtering with Tags

### Include Tags (AND logic)

Only return images that have **all** of the specified tags:

export const IncludeTagsExample = () => {
  const baseUrl = useApiBaseUrl();
  return <CodeBlock language="bash">{`curl "${baseUrl}/images?IncludedTags=waifu&IncludedTags=maid"`}</CodeBlock>;
};

<IncludeTagsExample />

### Exclude Tags (OR logic)

Exclude images that have **any** of the specified tags:

export const ExcludeTagsExample = () => {
  const baseUrl = useApiBaseUrl();
  return <CodeBlock language="bash">{`curl "${baseUrl}/images?ExcludedTags=maid&ExcludedTags=uniform"`}</CodeBlock>;
};

<ExcludeTagsExample />

### Combining Include and Exclude

export const CombineTagsExample = () => {
  const baseUrl = useApiBaseUrl();
  return <CodeBlock language="bash">{`curl "${baseUrl}/images?IncludedTags=waifu&ExcludedTags=maid"`}</CodeBlock>;
};

<CombineTagsExample />
